# Meu Portfólio Pessoal 

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar a minha trajetória, projetos e competências na área de tecnologia.

## Link do Projeto
[**Acesse ao portfólio online clicando aqui!**](https://joaomalta27.github.io/Meu_Portifolio/) 

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização, layout responsivo (Flexbox/Grid) e variáveis CSS.
* **JavaScript:** Interatividade, navegação suave e sistema de alternância entre Modo Claro/Escuro.

## Funcionalidades
* **Tema Dinâmico:** Alternância entre Modo Claro e Modo Escuro guardada no navegador (Local Storage).
* **Responsividade:** Layout adaptável para telemóveis e ecrãs menores.
* **Projetos:** Demonstração visual de aplicações como o *Escalonador de Processos* e o *Sistema de Reservas*.
